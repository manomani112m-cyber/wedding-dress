# Wedding Dress — Factory Management

نظام إدارة أولي لمصنع فساتين الأفراح.

## Preview
- افتح `index.html` في المتصفح.
- الحساب التجريبي: `admin` / `admin123`.

## الوحدات
- Dashboard
- الفساتين والموديلات
- المبيعات والحجوزات والإيجارات
- الفواتير القابلة للطباعة
- التصنيع ومراحل القماش/القص/الخياطة/السوستة/التطريز/التشطيب
- تكلفة التصنيع
- الخامات والمخزون وحركات الصرف والإضافة
- المشتريات
- الموردون
- المصروفات
- العملاء والقياسات والملاحظات
- التقارير والطباعة وCSV
- المستخدمون والأدوار والصلاحيات
- سجل نشاط محلي

## ملاحظة أمنية مهمة
هذه النسخة Preview تعمل بالكامل داخل المتصفح باستخدام localStorage. تسجيل الدخول والصلاحيات هنا ليست حماية حقيقية للإنتاج. عند تشغيل النظام فعليًا على الإنترنت يجب إضافة Backend وقاعدة بيانات ونظام جلسات/مصادقة حقيقي، وعدم تخزين كلمات المرور كنص صريح.

## GitHub Pages
يمكن نشر هذه النسخة كـPreview على GitHub Pages لأنها ملفات HTML/CSS/JS ثابتة. أما التشغيل التجاري متعدد المستخدمين فيحتاج Backend/Database بالإضافة إلى الواجهة.
